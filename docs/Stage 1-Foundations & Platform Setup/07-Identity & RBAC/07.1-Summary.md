# Identity and RBAC Summary

Daedalus uses a tenant-scoped identity model, role-based access control (RBAC), and module-level permission bundles. Auth is the authoritative identity service: it authenticates users, issues short-lived signed JWTs, and manages roles and permissions.

## Authorization model

The policy engine evaluates access in this order:

`User → Roles → Permissions → Module → Tenant → Resource`

- A user may have one or more roles, and each role resolves to explicit permissions.
- Permissions are scoped to a module and evaluated within the user's tenant context.
- Resource-level checks enforce ownership, assignment, and other domain rules that cannot be represented by a module permission alone.
- A valid JWT authenticates the caller but never grants access to another tenant or resource.

## Enforcement boundaries

The API Gateway validates the JWT signature, issuer, audience, expiry, and required claims before routing requests. It performs coarse authentication and policy checks, then propagates the trusted identity, tenant context, correlation ID, and trace context.

Each target service independently enforces tenant and resource authorization for its own data. Services do not rely on the Gateway as their only authorization boundary, access another service's tables, or accept tenant context solely from client input. PostgreSQL queries and events use `tenant_id` and `tenantId`, respectively.

The Control Panel Shell displays authorization-aware views but does not enforce security decisions. Backend services use managed identities and least-privilege access for Azure resources; user roles and permissions remain managed by Auth.

## Audit and operations

Authentication failures, authorization denials, role and permission changes, and administrative actions are recorded with the actor, tenant, target, decision, and `correlationId`. Logs and events redact tokens, credentials, and other secret values. Changes to roles or permission bundles require review and are deployed consistently across environments.
