# Identity Model — Tenant‑Scoped + External Identity Provider Support

## Hybrid Identity Model
- Internal user accounts (email + password)
- Optional external identity providers (Azure AD, Google Workspace, Okta)
- Tenant‑scoped user membership
- Service accounts for automation

## Why this is the right choice:
- Supports SaaS onboarding (email/password)
- Supports enterprise customers (SSO)
- Matches your existing schema (users, tenant_id)
- Enables secure automation via service accounts

Avoid:
- Global roles across tenants
- Per‑module identity stores. These break multi‑tenant isolation.
