# High-Level Architecture

Daedalus is a multi-tenant SaaS control panel. The **Control Panel Shell** is a presentation-only web application: it renders navigation, tenant context, forms, and views, but owns no domain logic or data. The **API Gateway is the sole external entry point** for the Shell, users, integrations, and other external clients.

```text
Users / external integrations
              |
      Control Panel Shell (presentation only)
              |
        API Gateway (only public entry point)
              |
  +-----------+-----------+-----------+-----------+
  |           |           |           |           |
 Auth   Customers   Bookings   Scheduling   Jobs
  |           |           |           |           |
 Payments -------- Notifications ----------------+
              |
 PostgreSQL Flexible Server | Azure Service Bus | Key Vault
```

## Canonical services

- **Auth** authenticates users and issues JWTs; it owns identity, roles, and permissions.
- **Customers** owns customer profiles and customer lifecycle data.
- **Bookings** owns booking requests, status, and booking-level pricing inputs.
- **Scheduling** owns availability, assignment, and schedule commitments.
- **Jobs** owns operational execution, checklists, completion, and job status.
- **Payments** owns payment intents, transactions, reconciliation, and provider references.
- **Notifications** owns templates, delivery requests, channel status, and message history.

Each service owns a schema in PostgreSQL Flexible Server. A separate database per service is not required initially. Services never read or write another service's tables; cross-service data is obtained through APIs or events.

## Platform components

- **API Gateway:** routing, JWT signature validation, rate limiting, API versioning, correlation IDs, and the canonical API envelope.
- **PostgreSQL Flexible Server:** relational platform with service-owned schemas and `tenant_id` on tenant-scoped records.
- **Azure Service Bus:** default asynchronous messaging technology for commands and events.
- **Azure Key Vault:** stores integration secret values; PostgreSQL stores only secret references and metadata.
- **Azure Monitor/Application Insights:** logs, metrics, traces, and operational alerting.
