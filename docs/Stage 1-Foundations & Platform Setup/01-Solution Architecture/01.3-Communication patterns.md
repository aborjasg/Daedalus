# Communication Patterns

Daedalus uses synchronous HTTPS APIs for user-facing request/response interactions and Azure Service Bus for asynchronous commands and events. The API Gateway is the only external entry point; east-west service calls use private networking and authenticated service identities, not the public Gateway surface.

## Synchronous APIs

The Shell calls versioned Gateway endpoints. The Gateway validates the JWT, adds or propagates `correlationId`, routes to one or more services, and returns the canonical envelope:

```json
{"success":true,"data":{},"errors":[],"correlationId":"corr-123"}
```

Writes require idempotency keys where retries could duplicate work. Timeouts, bounded retries with exponential backoff, circuit breakers, and pagination are required. A synchronous call is appropriate when the caller needs an immediate result, such as loading customer details or creating a booking request.

## Azure Service Bus

Azure Service Bus is the default messaging technology. Use queues for commands/work distribution and topics/subscriptions for events. Delivery is at least once; consumers must be idempotent, acknowledge only after durable processing, and use dead-letter queues for poison messages. Ordering is guaranteed only within the chosen session/partition strategy.

Every event uses this envelope:

```json
{"eventId":"evt-123","eventType":"BookingCreated","occurredAt":"2026-09-18T20:00:00Z","correlationId":"corr-123","tenantId":"tenant-1","sourceService":"Bookings","payload":{}}
```

`tenantId` is used in APIs and events; `tenant_id` is used in PostgreSQL. Event contracts are versioned and backward compatible.

## Canonical flows

- Booking created: Bookings persists, publishes `BookingCreated`; Scheduling consumes it and publishes availability/assignment facts; Notifications sends confirmations.
- Job completed: Jobs publishes `JobCompleted`; Payments consumes it to create or settle a payment intent; Notifications sends the receipt/status update.
- Payment failed: Payments publishes `PaymentFailed`; Notifications delivers an alert and the Shell reads status through the Gateway.

All messages carry correlation context and produce structured logs, metrics, and traces. Services do not publish sensitive secret values.
