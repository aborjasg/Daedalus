# ER Diagram (Logical, Service-Owned)

```text
AUTH schema
TENANTS 1──N TENANT_MEMBERSHIPS N──1 USERS
USERS N──N ROLES (USER_ROLES) N──N PERMISSIONS (ROLE_PERMISSIONS)

CUSTOMERS schema
TENANT 1──N CUSTOMERS 1──N CONTACTS / ADDRESSES

BOOKINGS schema
CUSTOMER_REF 1──N BOOKINGS

SCHEDULING schema
BOOKING_REF 1──N ASSIGNMENTS

JOBS schema
BOOKING_REF 1──N JOBS 1──N CHECKLIST_ITEMS / EVIDENCE

PAYMENTS schema
BOOKING_OR_JOB_REF 1──N PAYMENT_INTENTS 1──N TRANSACTIONS / REFUNDS

NOTIFICATIONS schema
TENANT 1──N TEMPLATES 1──N NOTIFICATION_REQUESTS 1──N DELIVERY_ATTEMPTS
```

References across lines are IDs and event/API contracts, not foreign keys or joins across service-owned tables. Every tenant-scoped entity carries `tenant_id`; APIs and event envelopes expose `tenantId`.
