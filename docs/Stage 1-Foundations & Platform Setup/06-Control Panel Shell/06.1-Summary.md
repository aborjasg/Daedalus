# Control Panel Shell Summary

The Control Panel Shell is a presentation-only web application. It owns
layout, navigation, tenant-context display, transient view/form state, and
accessibility. It does not own domain logic, persistence, service credentials,
or event subscriptions.

All backend access goes through the API Gateway, the sole external entry
point. The Shell sends authentication and correlation context to documented
Gateway routes; Auth owns identity and permissions, and each target service
enforces tenant and resource authorization. The Shell never connects to
PostgreSQL, reads service tables, calls private services directly, or reads
Key Vault.

The Shell composes user-facing views for customers, bookings, quotes,
scheduling, jobs, payments, notifications, and Auth-managed administration.
Quote Estimator calculates tenant-scoped estimates through its Gateway API;
the Shell displays input forms and results but does not calculate authoritative
prices. Bookings remains the owner of booking lifecycle and accepted booking
price snapshots. Long-running state is displayed from API responses and
refreshed through Gateway-mediated status requests. Domain events remain
internal to services and Azure Service Bus.
