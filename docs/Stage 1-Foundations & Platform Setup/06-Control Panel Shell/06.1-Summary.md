# Control Panel Shell Summary

The Control Panel Shell is a presentation-only web application. It owns layout, navigation, tenant context display, client-side form/view state, and accessibility. It does not own business rules, domain persistence, service credentials, or event subscriptions.

All data access goes through the API Gateway, the sole external entry point. The Shell sends the JWT and correlation context to Gateway endpoints; services, not the Shell, enforce tenant/resource authorization. The Shell never connects to PostgreSQL, reads service tables, calls private services directly, or reads Key Vault.

The Shell composes views for customers, bookings, schedules, jobs, payments, notifications, and Auth-managed administration. Long-running state is displayed by polling or Gateway-mediated status endpoints. Domain events remain internal to services and Azure Service Bus.
