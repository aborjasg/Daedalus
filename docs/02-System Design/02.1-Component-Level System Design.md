- Data protection: Encryption at rest/in transit, key management, secrets handling.

⚙️ 1. Runtime Execution Constraints

		○ Event projections

📡 2. API & Communication Constraints
2.1 API Gateway Enforcement

	• RBAC enforced at the gateway, not at domain services.

2.2 Idempotency Requirements
All write operations must be idempotent:
	• POST /bookings
	• POST /jobs/assign
	• POST /notifications/email
	• PATCH /users/{id}
Reason:
	• Event replay
	• Retry logic
	• At-least-once delivery guarantees
2.3 Event Delivery Semantics
	• At-least-once delivery
	• Consumers must be idempotent
	• No consumer may assume event ordering
	• No consumer may block on synchronous event processing
🧱 3. Data & Storage Constraints
